A Python program that writes a one-star review by a houseplant of its
human owner: watered like a rumor, outshone by a plastic cactus.

Competition: [One Star, Written in Sap on make.fun](https://make.fun/bounty/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4)

## Run

```sh
python3 main.py
```

This writes the single-line entry to `/output/entry.txt` (UTF-8).
